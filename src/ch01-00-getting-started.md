# Bắt Đầu

Hãy cùng bắt đầu hành trình với Rust! Có rất nhiều thứ cần học, nhưng mọi hành trình đều phải bắt đầu từ đâu đó. Trong chương này, chúng ta sẽ thảo luận về:

- Cài đặt Rust trên Linux, macOS và Windows
- Viết một chương trình in ra `Hello, world!`
- Sử dụng `cargo`, package manager và build system của Rust
